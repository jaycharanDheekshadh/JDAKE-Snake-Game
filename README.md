# 🐍 JDAKE Snake Game – V1.1 ULTRA
The Entire code for Arduino IDE:
[Sketch.txt](https://github.com/user-attachments/files/34740381/Sketch.txt)


Welcome to JDAKE Snake Game! A feature-packed Snake game built using Arduino Mega 2560, an OLED display, and a joystick. Any bugs to Issues section

## 🎮 Features

- Multiple difficulty levels
- 4 game worlds
- World bosses
- Achievements and medals
- Daily challenges
- Snake skins and accessories
- Secret quests
- Statistics and progress tracking
- EEPROM save system
- Tutorial and settings menus

## 🔧 Hardware Required

- Arduino Mega 2560
- 128×64 SSD1306 OLED display
- Joystick module
- Connecting wires

## 🔌 Wiring

### OLED Display

| OLED | Arduino Mega |
|---|---|
| GND | GND |
| VDD | 3.3V |
| SCK / SCL | Pin 21 |
| SDA | Pin 20 |

### Joystick

| Joystick | Arduino Mega |
|---|---|
| GND | GND |
| +5V | 5V |
| VRX | A0 |
| VRY | A1 |
| SW | Pin 2 |

## 💾 Saving Progress

The game uses the Arduino Mega's EEPROM storage to save supported game progress and skin data.
